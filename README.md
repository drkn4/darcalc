\# だるくん電卓



\## 概要

自分用高機能電卓アプリ。



HTML / CSS / JavaScript で開発。

将来的に Android / iPhone アプリ化予定。



\---



\## 実装済み機能



\- リアルタイム履歴表示

\- 履歴保存（最大30件）

\- 履歴全画面表示

\- 履歴選択 / コピー / 削除

\- ダークモード

\- 振動機能

\- 税込 / 税抜

\- F1計算

\- 小数点桁数変更

\- 定数計算

\- レスポンシブ対応



\---
